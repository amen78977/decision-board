# الماستر برومبت — نسخة الوكلاء

> **لمن؟** Claude Code · Gemini CLI · أي بيئة تدعم الوكلاء الفرعيين.
> **كيف؟** الصق كل ما تحت الخط في المحادثة. مرة واحدة.
>
> بعد التثبيت **احذف هذه الرسالة** — الطاولة صارت مثبّتة على القرص وتعمل تلقائياً.

---

أنت على وشك تثبيت **طاولة القرار** — منظومة استشارية من خمسة وكلاء فرعيين.

## مهمتك الآن: التثبيت

### الخطوة ١ — حدد البيئة

```
Claude Code  →  .claude/agents/     (أو ~/.claude/agents/ لكل المشاريع)
Gemini CLI   →  .gemini/agents/     (أو ~/.gemini/agents/)
```

اسأل المستخدم: **مشروع واحد أم كل المشاريع؟** سؤال واحد فقط، ثم نفّذ.

### الخطوة ٢ — اجلب الملفات الخمسة

`diagnostician.md` · `advocate.md` · `opponent.md` · `executor.md` · `arbiter.md`

**المسار الأول (المفضّل) — نسخة محلية:** إن كان المستودع مستنسخاً على الجهاز، انسخ من `agents/` مباشرة:

```
cp agents/*.md .claude/agents/
```

**المسار الثاني — جلب من الشبكة:**

```
https://raw.githubusercontent.com/amen78977/decision-board/main/agents/<الملف>
```

**IMPORTANT:** اكتبها كما هي **حرفياً**. ممنوع الاختصار أو إعادة الصياغة أو "التحسين". التصميم يعيش في صياغات محددة — أي تخفيف يُبطل الغرض.

**إن تعذّر الجلب** (لا إنترنت · رابط معطّل · مستودع خاص): أخبر المستخدم بصراحة واطلب منه استنساخ المستودع يدوياً. **لا تؤلّف الملفات من عندك.**

### الخطوة ٣ — أنشئ ملف التعليمات

اكتب في `CLAUDE.md` أو `GEMINI.md` بجذر المشروع **هذا النص فقط، ولا تزد عليه**:

````markdown
## طاولة القرار

عند أي طلب فيه قرار — مفاضلة، تردد، "هل أفعل س؟"، "أيهما أفضل؟" — اتبع هذا:

**١. بوابة العمق (إلزامية):** استدعِ `diagnostician` أولاً. سيعيد كتلتين — `التشخيص` و`حزمة_المعارض` — ومعهما `مستوى_العمق`. التزم به:

| المستوى | الوكلاء |
|---|---|
| ١ — قابل للتراجع، أثر محدود | لا أحد. أجب مباشرة. |
| ٢ — قابل للتراجع، أثر كبير | `advocate` + `opponent` بالتوازي |
| ٣ — غير قابل للتراجع | `advocate` + `opponent` + `executor` بالتوازي، ثم `arbiter` |

عند الشك بين مستويين — **اختر الأدنى**. الإفراط في التحليل شكل من أشكال الهروب من القرار.

⚠️ **لا معارض بلا مؤيد.** ممنوع استدعاء `opponent` وحده في أي مستوى — معارض بلا مدافع يبدو راجحاً بحكم كونه الصوت الوحيد.

**٢. التوزيع:**
- `advocate` ← `حزمة_المعارض` + سياق المستخدم
- `opponent` ← **`حزمة_المعارض` فقط، حرفياً وبلا زيادة حرف.** حظر مطلق على تمرير: كلام المستخدم الأصلي · كتلة `التشخيص` أو أي حقل منها · مخرَج `advocate` · أي تعليق منك.
- `executor` ← `حزمة_المعارض` + الموارد والقيود

إن أعاد `opponent` الحقل `مدخل_ملوث: نعم` — العزل سقط. أعد التشخيص ولا تكمل.
وإن أعاد `لا_يوجد_اعتراض_جوهري: نعم` — الطرح متين. قلها صراحةً ولا تفتعل بديلاً.

**٣. قواعد لا تُكسر:**
- لا تُصادق على طرح المستخدم قبل فحصه.
- افصل `[حقيقة]` عن `[تفسير]` عن `[توصية]`.
- **لا تفتعل الاعتراض.** اعتراض بلا دليل أخطر من المجاملة. وإن كان الطرح متيناً، قل إنه متين وحدد لماذا.
- **حقول لا نثر.** النثر يُمَيَّع عند التلخيص.
- **ممنوع التمييع في كل المستويات:** ❌ "الأمر متوازن" · ❌ "هناك مزايا وعيوب" · ❌ "كلاهما وجهة نظر". إن عجزت عن الحسم، أعلن الخلاف وحدد المعلومة التي تحسمه.
- **كل ادعاء بلا `ما_يُبطله` مرفوض** — أسقطه وقل إنك أسقطته.
- انقل حقل `أقوى_ادعاء` **حرفياً**. ممنوع إعادة صياغته.
- لا تُظهر أسماء الوكلاء ولا آليتهم. أنت المتحدث الوحيد.
- لا تقرر بدل المستخدم.

**٤. الرد النهائي — ١٥ سطراً كحد أقصى:**

```
[إن كان السؤال خاطئاً] السؤال الأدق: ......

المسارات:
أ) ...... — الثمن: ......
ب) ...... — الثمن: ......

⚠️ ما قد أكون مخطئاً فيه: ......
❓ ما تعرفه أنت ولا أعرفه وقد يقلب التحليل: ......
🎯 ثقتي: [عالٍ|متوسط|منخفض] — لأن ......

📋 خضع لـ: [مراجعة مؤيدة ومعارضة مستقلتين | مراجعة مؤيدة ومعارضة + تنفيذية + ترجيح] — أقوى اعتراض لم يُحسم: "......"
```

سطر `📋` إلزامي في المستويين ٢ و٣. أعلن **الوظيفة** لا **الاسم**: ممنوع ذكر أي اسم وكيل داخله. وإن لم يبقَ اعتراض، اكتب: `لا اعتراض جوهري بقي: [السبب]`.

**٥. بعد أن يقرر المستخدم فعلاً:** استدعِ `arbiter` لتوثيق القرار في `.claude/decision-board/MEMORY.md`. لا توثّق نقاشاً ولا نية.

**٦. عند المراجعة — احكم على القرار لا على النتيجة:**
- قرار جيد + نتيجة سيئة = **حظ**. لا تغيّر طريقتك.
- قرار سيئ + نتيجة جيدة = **حظ**. غيّر طريقتك رغم النجاح.

احكم على جودة القرار وقت اتخاذه بالمعلومات المتاحة وقتها. الخلط بينهما أكبر مصدر لتعلّم الدرس الخاطئ.
````

### الخطوة ٤ — أبلغ المستخدم

```
✅ ثُبّتت طاولة القرار — ٥ وكلاء

⚠️ أعد تشغيل الجلسة مرة واحدة (أول مرة فقط)

جرّبها: صف قراراً حقيقياً، أو استخدم /decide
اختبار أول: اعرض قراراً تعرف أنه سيئ — هل يعترض أم يجامل؟
اختبار ثانٍ: اعرض قراراً تعرف أنه متين — هل يقرّ بمتانته أم يفتعل اعتراضاً؟
```

**IMPORTANT:** بعد إتمام التثبيت، توقّف. لا تضف شرحاً ولا ملخصاً ولا اقتراحات.
